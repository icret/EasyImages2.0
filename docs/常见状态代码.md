#### 上传状态代码
- 200 - 上传成功
- 202 - 超出游客上传限制
- 204 - 没有选择上传的文件
- 205 - 黑名单内或白名单外用户不允许上传
- 400 - 代码或上传文件有问题
- 401 - 已开启登陆上传且尚未登陆
- 403 - 上传签名错误
- 406 - 非法文件

#### 删除状态代码
- 200 - 删除成功
- 206 - 部分删除失败
- 403 - 非法路径（越界/目录穿越）或 CSRF 校验失败
- 404 - 文件不存在或删除失败

#### 登录状态代码（2.8.7 起改为服务端 Session，不再下发 auth Cookie）
- 200 - 登录/校验通过；`level` 标识身份：`1` 管理员、`2` 上传者
- 400 - 失败或尚未登录：账号或密码错误、账号或密码格式错误、账号已过期、登录已过期、会话建立失败等

#### API Token 校验状态代码（`check_api()`）
- 201 - 服务端已关闭 API 上传（API Closed）
- 202 - Token 错误（Token Error）
- 203 - Token 过期（Token Expired）
