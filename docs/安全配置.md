上传/存储目录必须禁止服务端执行脚本，配置目录必须禁止被 Web 直接访问。Apache 依赖目录内 `.htaccess`（程序已内置，默认禁止脚本执行与隐藏文件访问）；Nginx、Caddy、Lighttpd **不读取 `.htaccess`**，需在服务器配置中补等价防护。

## Apache

存储目录 `i/` 与配置目录 `config/` 均已内置 `.htaccess`（`i/` 禁脚本执行与隐藏文件，`config/` 拒绝一切访问）。若站点未开启 `AllowOverride`，`.htaccess` 不生效，需在全局配置中加入等价规则：

```Apache
<Directory "/var/www/html/i">
    AcceptPathInfo Off
    php_flag engine off
    <FilesMatch "(?i)\.(php[0-9]?|phtml|phps|pht|phar|pl|py|jsp|asp|aspx|sh|cgi|htaccess|user\.ini)$">
        Require all denied
    </FilesMatch>
</Directory>

# 配置目录内含凭据，拒绝一切 Web 访问
<Directory "/var/www/html/config">
    Require all denied
</Directory>
```

## Nginx

- 配置目录内含账号密码等凭据，禁止任何 Web 访问。
- 存储与公共目录禁止执行任何脚本扩展名（口径与程序内置白名单一致）。
- 用 `try_files $uri =404` 让 PHP 仅处理真实存在的脚本，杜绝 `/i/x.jpg/evil.php` 这类 PATH_INFO 解析执行。

```Nginx
# 配置目录禁止任何 Web 访问（内含凭据）
location ^~ /config/ {
    deny all;
    return 404;
}

# 存储与公共目录禁止执行脚本
location ~* ^/(i|public|docs)/.*\.(php|php[0-9]|phtml|phar|pht|cgi|pl|py|sh|asp|aspx|jsp)$ {
    deny all;
    return 404;
}

# PHP 仅处理真实存在的脚本（fastcgi_pass 按你的 PHP-FPM 监听填写）
location ~ \.php$ {
    try_files $uri =404;
    include fastcgi_params;
    fastcgi_pass <PHP-FPM 监听地址>;
}
```

## Lighttpd

```Lighttpd
$HTTP["url"] =~ "^/(config|i|public|docs)/" {
    fastcgi.server = ()
}
```
